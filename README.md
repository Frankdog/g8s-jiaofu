# 8上教辅（八年级上册）

孩子八年级上学期的教辅分卷库。原始整本 PDF 保留在本地 `~/Downloads/教辅资料/`（未做任何改动），本仓库只存**切好的分卷**，方便在 GitHub 网页端直接翻页、在手机上分段看，也绕开 GitHub「单文件 100MB」的硬限制。

## 怎么切的

这些教辅都是扫描件，单页 1～3 MB，整本 190～300 MB，直接上传会被 GitHub 拒绝。切分用 PyMuPDF **只搬运页面对象、不重新编码图片**，画质与原书完全一致（已逐卷抽样渲染、像素级比对，0 差异）。

- **物理主书：按章节切。** 扫描件没有书签也没有文字层，所以先 OCR 目录页还原章节：用 200/300 两档分辨率交叉比对右栏页码（单次识别常把 `046` 读成 `LtO`），再逐章 OCR 校验起始页确实印着该章标题。文件名直接带章名。
- **答案册、几何模型：按体积切。** 答案册没有目录页；几何模型的页码内嵌在「模型3 线与角⋯6」这种条目里，无法可靠配对。这两种按每卷 ≤38 MB 切，文件名带页码范围。

单卷上限 38 MB：GitHub 单文件限制 100 MB，留足余量；38 MB 也刚好适合手机加载。章节本身超过 38 MB 时会续拆成 `-01` / `-02`。

## 新增一本书

```bash
# 有目录页的（主书优先用这个，按章切）
python tools/toc_split.py 源文件.pdf 目标目录 --prefix "主书-"

# 没有目录页的（按体积切）
python tools/split_pdf.py 源文件.pdf 目标目录 --prefix "答案-" --max-mb 38
```

两个脚本都会自动分卷、递归校验每卷不超标，并保证所有卷页数之和等于原书页数。

## 合并回整本

```bash
python - <<'PY'
import glob, pymupdf
out = pymupdf.open()
for f in sorted(glob.glob('物理/4星学霸题中题（2027版）/主书/*.pdf')):
    out.insert_pdf(pymupdf.open(f))
out.save('合并.pdf')
PY
```
